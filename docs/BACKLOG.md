# Architecture experiment backlog

This is a living collection of candidate experiments, not a release plan or a complete feature list. Items may be added, split, reordered, or discarded as MiraiSpace tests new ideas. A candidate receives a detailed task only when it is selected for design or implementation.

## Foundation candidates

- Avalonia and Generic Host lifecycle integration
- Module entry point and explicit built-in composition
- Plugin manifest, discovery, diagnostics, and startup lifecycle
- Architecture tests for dependency direction
- In-memory messaging and reactive state ownership
- Platform capability contracts
- Application session, identity, permissions, and rational multi-tenancy boundaries
- Demo API and realtime server when a client experiment requires them

## Feature experiments

- Navigation and page activation
- Menu composition and reactive access
- View resolution and plugin overrides
- Universal tables and data editors
- Profile and current-user state
- Settings scopes, persistence, and contributions
- Realtime transport, reconnect, and state refresh
- Docking and floating panels
- Layout persistence
- Multi-window workflows
- Command palette, shortcuts, and contextual actions
- Notifications and background activity
- Document, task, and reference-data demonstrations

## Platform experiments

- Desktop behavior on Windows, Linux, and macOS
- Browser host and compile-time module composition
- Android and other mobile Avalonia targets
- Host-specific plugin and platform capabilities
