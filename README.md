# MiraiSpace

Кроссплатформенное приложение на Avalonia для десктопа и браузера.

Инструкции и переиспользуемые навыки для coding agents находятся в
[`AGENTS.md`](AGENTS.md) и [`.agents/skills`](.agents/skills). Набор включает
процессы уточнения требований, проектирование и TDD, а также инструкции по
Avalonia, .NET, ReactiveUI и Eremex Controls. Источники внешних навыков
зафиксированы в [`skills-lock.json`](skills-lock.json).
